## 1. 项目概述

### 1.1 一句话定位

一个以「世界观」为容器的创作与共建平台——人人可浏览、可参与共创，Web 端负责建造与管理，手机端负责发现与阅读。

### 1.2 核心能力

| 能力 | 优先级 | 当前状态 |
|------|--------|----------|
| 浏览（发现世界观、阅读作品与 Wiki） | P0 | ✅ 已实现 |
| 共创（投稿小说、剧情、美术等） | P0 | ✅ 已实现 |
| 世界观 Wiki 主页（词条、时间轴、发展史） | P0 | ✅ 已实现 |
| 写作（绑定世界观、自动链接词条） | P1 | ✅ 已实现 |
| 权限（创建者配置审核/开放策略） | P0 | ⚠️ 字段已预留，审核流未做 |
| Fork（基于已有世界观派生分支） | P1 | ❌ 字段已预留，逻辑未做 |
| 聊天/讨论 | P2 | ❌ 未做 |
| 商业化（订阅、打赏、数字作品） | P3 | ❌ 未做 |

### 1.3 目标用户

- OC / 原创设定爱好者
- 小说、剧本、图文创作者
- 跑团（TRPG）主持与玩家
- 语 C、同人、世界观爱好者
- 独立世界观 IP 的创建者与共建者

### 1.4 当前开发阶段

项目处于 **Phase 1 MVP 已完成** 状态，核心闭环已打通：

> 注册登录 → 创建世界观 → 编辑 Wiki（人物/物品/时间轴）→ 配置样式 → 发布 → 创作作品 → 广场展示 → 阅读页（含 Wiki 标注联动）

## 2. 技术可行性分析

### 2.1 技术栈评估

| 层 | 技术选型 | 评价 | 评分 |
|----|----------|------|------|
| 前端 | Next.js 16 + React 19 + TypeScript + CSS Modules | 主流、生态成熟、SSR 支持好，适合内容型平台 | ★★★★★ |
| 后端 | Node.js + TypeScript (Fastify 5) | 轻量高效，类型安全，前后端同语言降低协作成本 | ★★★★☆ |
| 数据库 | PostgreSQL（裸 SQL，无 ORM） | 世界级关系型数据库，适合复杂关系查询；裸 SQL 灵活但维护成本偏高 | ★★★★☆ |
| 鸿蒙端 | ArkTS（后续） | 跟随鸿蒙生态，有政策红利但生态尚在发展期 | ★★★☆☆ |

**总评：技术选型务实且现代，前后端分离 + API 优先的架构为多端扩展打好基础。**

### 2.2 架构质量

**亮点：**
- ✅ API 优先设计，Web 与鸿蒙端共用同一套后端 API
- ✅ 数据模型设计规范（3NF、软删除、部分唯一索引、CHECK 约束）
- ✅ JWT 认证 + refresh token，用户隔离从 JWT 取 userId 不信任客户端
- ✅ 存储层抽象（local 驱动已实现，S3/OSS 预留接口）
- ✅ 前后端共享 homepageConfig 逻辑，避免配置不一致
- ✅ 阅读器支持滚动/翻页双模式 + Wiki 标注侧栏，体验设计用心

**技术债/待改进：**
- ⚠️ 裸 SQL 无 ORM — 初期灵活，但随表结构增长，迁移和查询维护成本会上升
- ⚠️ 无缓存层 — 当前 COUNT 查询点赞数，用户量增长后需引入 Redis
- ⚠️ 无测试代码 — MVP 阶段可接受，进入正式运营前必须补
- ⚠️ Git 无提交记录 — 代码未纳入版本管理（或为本地仓库），存在代码安全风险
- ⚠️ 无 CI/CD — 部署流程未建立

### 2.3 技术可行性结论

| 维度 | 评分 | 说明 |
|------|------|------|
| 架构合理性 | 8.5/10 | API 优先 + 数据隔离设计清晰 |
| 代码质量 | 7.5/10 | 结构清晰，但缺测试和无 ORM 是隐患 |
| 技术成熟度 | 8.5/10 | 全栈 TypeScript，团队学习曲线低 |
| 可扩展性 | 7.5/10 | 架构预留了扩展点，但部分基础设施（缓存、队列）缺失 |
| **综合** | **8.0/10** | **技术可行，MVP 已验证核心闭环** |

## 3. 产品设计评估

### 3.1 设计文档体系

项目拥有非常完整的设计文档体系，这在个人/小团队项目中极为罕见：

| 文档 | 内容 | 质量 |
|------|------|------|
| `design.md` | 产品设计文档（834 行） | 覆盖产品概述、用户角色、信息架构、功能详述、数据模型、阶段规划 |
| `visual.md` | 视觉规范（261 行） | 色彩系统、字体、组件规范、动效原则，定位「纸本设定集」气质 |
| `frontend.md` | 前端设计文档（398 行） | 页面清单、跳转关系、API 对照、组件复用 |
| `tech-stack.md` | 技术选型 | 已确认，含架构图 |
| `database/` | 数据库设计（5 个文档） | ER 总览 + 分域设计 + DDL + 索引策略 |
| `inspiration/` | 灵感草案（4 份） | 广场三栏、入口 Wiki 写作、冷启动助手 Agent |

### 3.2 产品设计亮点

1. **「作品优先」的广场设计** — 用户进站先看作品而非世界观目录，降低了冷启动认知门槛，这是对传统 Wiki 平台（如 Fandom）的重要改进

2. **每个世界观各自一套 Wiki** — 不是平台级总百科，而是每个世界独立的设定主页，这正确地匹配了 OC/世界观创作者的实际需求

3. **纸本设定集视觉气质** — 差异化定位明确，避开了科技仪表盘/社交信息流的同质化设计，与目标用户（创作者、设定爱好者）的审美高度契合

4. **冷启动助手 Agent 构想** — 丢材料 → Agent 读内容 → 结构化建议 → 人确认 → 生成草稿世界。这解决了「空白编辑器恐惧症」，是降低创作门槛的关键创新

5. **写作与设定联动** — 写作时 `[[词条名]]` 自动链接该世界 Wiki 词条，作品与设定形成闭环，这是核心差异化能力

6. **渐进开放策略** — 先创建者主导+审核制共创，再逐步放开人人可编辑，符合社区治理规律

7. **Fork 机制** — 基于已有世界观派生分支，类似 GitHub Fork，为 IP 扩展和社区裂变提供了技术基础

### 3.3 产品设计待改进

- ⚠️ **冷启动问题** — 虽然设计了 Agent 助手，但平台初期没有内容就没有用户，没有用户就没有内容的经典困境需要明确策略
- ⚠️ **用户路径过长** — 从注册到看到第一篇作品，路径为：注册 → 广场 → （空）→ 发现世界 → （空）→ 创建世界 → 编辑 → 发布，新用户极易流失
- ⚠️ **社交属性薄弱** — P2 的讨论功能推迟，但社区感是留存关键
- ⚠️ **搜索/推荐** — MVP 仅用「最新」排序，无推荐算法，长期需要个性化推荐

### 3.4 产品设计评分

| 维度 | 评分 | 说明 |
|------|------|------|
| 产品定位清晰度 | 9.0/10 | 目标用户、核心能力、差异化都非常清晰 |
| 设计完整度 | 9.0/10 | 文档体系完整度远超同类个人项目 |
| 用户体验设计 | 8.0/10 | 视觉气质突出，但新用户路径偏长 |
| 差异化 | 8.5/10 | Fork + 写作设定联动 + 纸本气质构成差异化组合 |
| **综合** | **8.6/10** | **产品设计水准高，执行思路清晰** |

## 4. 市场分析

### 4.1 全球世界观构建软件市场

根据市场研究报告（MarketIntelo, 2025）：

| 指标 | 数据 |
|------|------|
| 2025 年市场规模 | 3 亿美元 |
| 2034 年预测规模 | 6.3 亿美元 |
| 年复合增长率（CAGR） | 9.2% |
| 最大应用场景 | 游戏开发（38.5%） |
| 主要部署方式 | 云端（72.3%） |
| 最大区域市场 | 北美（45.2%） |

**关键驱动力：**
- 独立游戏开发爆发
- 创作者经济（Creator Economy）崛起
- 沉浸式叙事需求增长
- 教育领域采纳

### 4.2 中国市场机会

中国市场有几条独特的高增长赛道与本项目高度相关：

**（1）OC 文化崛起**

新一代二次元用户正从「同人二创」转向「OC 原创角色」：

| 平台 | OC 话题数据 |
|------|------------|
| 小红书 | 话题浏览量近 38 亿 |
| 抖音 | 相关播放量达 260 亿 |

OC 创作者需要：角色设定、世界观构建、作品展示、社区交流——这正是「无限企划」的核心能力。

**（2）同人创作市场高速增长**

- 同人文市场规模年增长 30%
- LOFTER 同人文学大赛吸引 4.6 万名创作者、3.3 万篇作品
- 话本小说平台仅奥特曼同人专题就超过 5 万部作品
- 头部同人作者月收入过万

**（3）大厂入局验证赛道**

百度已测试「次遇」App 入局二次元 OC 社区，提供千万级流量扶持和百万现金补贴，说明市场已被验证。

**（4）泛二次元用户基数**

- 2021 年泛二次元用户 4.6 亿
- 核心二次元用户 1.1 亿
- 预计 2026 年泛二次元人群突破 5.2 亿

### 4.3 市场定位

| 维度 | 定位 |
|------|------|
| 地域 | 中文互联网市场（中国大陆优先） |
| 语言 | 中文优先，架构支持国际化 |
| 用户层 | 创作者（设定构建） + 消费者（阅读发现） |
| 平台层 | Web 创作端 + 鸿蒙阅读端 |
| 差异化 | 世界观容器 + Fork 派生 + 写作设定联动 |

### 4.4 市场分析结论

全球世界观软件市场虽仅 3 亿美元，但中国市场存在一个**更大的相邻市场**——OC 文化 + 同人创作 + 泛二次元——用户基数以亿计，且年增长率 30%+。「无限企划」切入的不是 3 亿美元的传统 worldbuilding 工具市场，而是面向中文创作者的**世界观共创社交平台**赛道，天花板远高于全球 worldbuilding 软件市场。

## 5. 竞品对比

### 5.1 主要竞品

| 维度 | World Anvil | LOFTER | 话本小说 | Notion | **无限企划** |
|------|-------------|--------|----------|--------|-------------|
| 定位 | 世界观构建工具 | 同人创作社区 | 同人小说平台 | 通用笔记 | 世界观共创平台 |
| 核心能力 | 设定管理 + 展示 | 内容分发 + 社交 | 同人写作 + 变现 | 知识管理 | 设定 + 创作 + 社区 |
| Wiki 系统 | ✅ 专业 | ❌ | ❌ | ✅ 通用 | ✅ 每世界独立 |
| Fork | ❌ | ❌ | ❌ | ❌ | ✅ 设计中 |
| 写作-设定联动 | ❌ | ❌ | ❌ | ❌ | ✅ 核心特色 |
| 中文市场 | 弱 | 强 | 强 | 中 | 本土 |
| 用户基数 | 150 万+ | 千万级 | 百万级 | 亿级 | 0（起步） |
| 商业化 | 订阅制 | 打赏+广告 | 订阅分成 | 订阅制 | 待定 |

### 5.2 差异化分析

**vs World Anvil：**
- World Anvil 是**工具型**产品（个人用），无限企划是**社区型**产品（共创）
- World Anvil 无 Fork、无写作设定联动
- 无限企划中文优先，更贴合中国 OC/同人/跑团创作者习惯
- 但 World Anvil 功能深度远超当前 MVP（地图、角色关系图、剧本管理……）

**vs LOFTER / 话本：**
- LOFTER/话本是**内容分发平台**，设定管理能力薄弱
- 无限企划以「世界观」为容器，设定与作品形成闭环
- 但 LOFTER/话本有巨大的用户基数和成熟的内容分发机制

**vs Notion：**
- Notion 是通用工具，不做创作者社区
- 无限企划专注创作场景，体验更贴合

### 5.3 竞品分析结论

无限企划的**核心差异化**在于：
1. 每个世界观各自一套 Wiki + 共创社区（不是个人工具，是社区平台）
2. Fork 机制（世界观可派生，社区可裂变）
3. 写作-设定联动（写作时自动链接 Wiki 词条，设定反哺作品）

这三点组合在世界观构建赛道中**目前无直接竞品**。但需要注意：差异化不等于有需求，需要验证用户是否愿意为这些差异买单。

## 6. 商业价值评估

### 6.1 商业化路径

项目设计文档已规划了远期商业化方向：

| 模式 | 说明 | 可行性 | 预期时间 |
|------|------|--------|----------|
| 订阅 | 付费访问完整 Wiki、独家章节 | ⭐⭐⭐⭐ 需要「旗舰世界」做标杆 | Phase 4 |
| 打赏 | 对作品、世界观、作者打赏 | ⭐⭐⭐⭐⭐ 同人市场已验证 | Phase 3-4 |
| 数字售卖 | 设定集、插画集、小说章节 | ⭐⭐⭐ 需要 IP 价值积累 | Phase 4 |
| 平台增值 | 高级控制台、存储、数据分析 | ⭐⭐⭐ 工具型变现，天花板有限 | Phase 4 |
| IP 延伸 | 授权、周边、改编 | ⭐⭐ 路径最远但天花板最高 | Phase 5+ |

### 6.2 收入模型推演

假设进入稳定运营期（保守估计）：

| 指标 | 保守值 | 乐观值 |
|------|--------|--------|
| 月活创作者 | 5,000 | 50,000 |
| 付费率 | 3% | 8% |
| ARPPU（月均付费） | ¥30 | ¥50 |
| 月订阅收入 | ¥4,500 | ¥20,000 |
| 打赏抽成（10%） | ¥3,000 | ¥30,000 |
| 月总收入 | ¥7,500 | ¥50,000 |
| 年总收入 | ¥9 万 | ¥60 万 |

> 注：以上为非常早期的推算，仅说明收入模型的量级。要达到百万级年收入，需要 5-10 万月活创作者。

### 6.3 商业价值的核心逻辑

```
世界观数量 × 每个世界的作品密度 × 社区活跃度 = 平台价值
```

- **世界观数量**取决于创建门槛（冷启动 Agent 是关键）
- **作品密度**取决于创作工具体验（写作-设定联动是核心）
- **社区活跃度**取决于社交机制和内容分发（当前最弱）

### 6.4 商业价值评分

| 维度 | 评分 | 说明 |
|------|------|------|
| 市场规模 | 7.5/10 | 相邻市场大，但垂直赛道尚小 |
| 差异化护城河 | 8.0/10 | Fork + 写作设定联动组合独特，但易被模仿 |
| 变现路径清晰度 | 6.5/10 | 方向明确但距离变现尚远 |
| 增长潜力 | 8.0/10 | OC 文化 + 同人创作高增长，天花板高 |
| **综合** | **7.5/10** | **商业前景看好，但需要耐心和运营能力** |

## 7. 风险与挑战

### 7.1 产品风险

| 风险 | 等级 | 说明 | 缓解策略 |
|------|------|------|----------|
| 冷启动困境 | 🔴 高 | 平台型产品的经典难题：无内容→无用户→无内容 | 自建种子世界观；接入 AI 辅助生成；定向邀请 KOL 创作者 |
| 用户路径过长 | 🔴 高 | 新用户从注册到看到价值需 5+ 步操作 | 首页直接展示优质内容；「先逛再注册」；一键体验 |
| 社交属性薄弱 | 🟡 中 | P2 才做讨论，初期留存依赖内容质量 | 尽早加作品评论；引入「关注」推送 |
| 同质化竞争 | 🟡 中 | LOFTER/话本/百度次遇都在抢同一批用户 | 坚持世界观+设定联动差异化，不变成纯内容流 |

### 7.2 技术风险

| 风险 | 等级 | 说明 | 缓解策略 |
|------|------|------|----------|
| 无版本管理 | 🔴 高 | Git 无提交记录，代码安全无保障 | 立即推送到远程仓库 |
| 无测试覆盖 | 🟡 中 | 功能迭代速度会随复杂度增长而下降 | 关键路径补集成测试 |
| 无缓存层 | 🟢 低 | 当前用户量小，暂不紧急 | 预留 Redis 接入方案 |
| 裸 SQL 维护 | 🟡 中 | 表结构增长后迁移成本高 | 考虑引入轻量 Query Builder |
| 鸿蒙端投入 | 🟢 低 | 后续阶段，暂无风险 | 跟踪鸿蒙生态发展再决策 |

### 7.3 商业风险

| 风险 | 等级 | 说明 | 缓解策略 |
|------|------|------|----------|
| 变现周期长 | 🔴 高 | 平台型产品至少 1-2 年才有稳定收入 | 做好长期投入准备；先做工具价值再谈变现 |
| 版权与署名 | 🟡 中 | 共创涉及复杂版权关系 | 尽早制定投稿协议和 Fork 收益规则 |
| 内容审核 | 🔴 高 | UGC 平台的合规要求高 | 建立 AI 初审 + 人工复审机制 |
| 大厂降维打击 | 🟡 中 | 百度/字节随时可能做类似产品 | 建立社区粘性和创作者关系，这是大厂最难复制的 |

### 7.4 团队风险

### 8.2 总体判断

> **项目可行，商业价值有潜力，但窗口期有限。**

**核心论据：**

✅ **做对了的事：**
- 产品设计水准高，文档体系完整度远超同类个人项目
- 技术选型务实现代，MVP 已验证核心闭环
- 差异化定位（世界观容器 + Fork + 写作设定联动）在赛道中无直接竞品
- OC 文化 + 同人创作市场年增长 30%，市场被大厂入局验证

⚠️ **需要警惕的事：**
- 平台型产品的冷启动困境是最大杀手，需要明确种子内容策略
- 从 MVP 到有稳定收入至少 12-18 个月，需要可持续的投入
- 代码未纳入 Git 版本管理、无测试，正式运营前必须补齐工程化基础设施
- 独立开发者难以同时做好产品迭代 + 社区运营 + 商业化

### 8.3 优先行动建议

**立即做（1-2 周）：**
1. 📌 **推代码到远程 Git 仓库** — 消除代码安全风险
2. 📌 **补齐 .env.example 和部署文档** — 确保可复现部署
3. 📌 **确定目标用户画像** — 是 OC 画师？同人作者？跑团 DM？聚焦一类先打透

**短期做（1-3 个月）：**
4. 📌 **制作 3-5 个种子世界观** — 自己做或邀请创作者做，作为平台冷启动内容
5. 📌 **实现冷启动助手 Agent（A 档）** — 降低创建门槛，这是差异化关键
6. 📌 **上线公开预览版** — 收集真实用户反馈
7. 📌 **补关键路径集成测试** — 至少覆盖注册/创建世界/发布作品

**中期做（3-6 个月）：**

9. 📌 **加入作品评论 + 关注推送** — 社区感是留存关键
10. 📌 **探索第一批商业化试水** — 打赏功能优先，同人市场已验证

**长期做（6-12 个月）：**
