

## 1. 视觉定位

### 1.1 一句话

**纸本设定集气质**——像翻开一本正在被多人续写的世界观手册，而不是科技仪表盘或社交信息流。

### 1.2 关键词

| 要有 | 不要有 |
|------|--------|
| 书本、纸张、印刷感 | 霓虹、赛博、强发光 |
| 安静、可读、可沉浸 | 嘈杂、卡片墙、数据看板感 |
| 温暖纸色 + 沉稳墨色 | 纯白无菌 / 纯黑炫酷 |
| 细线、留白、层级清晰 | 厚阴影、大圆角、玻璃拟态堆叠 |
| 品牌名作为首屏主角 | 首屏塞满统计、标签、促销条 |

### 1.3 情绪板（文字版）

- 旧地图边缘的青绿标注
- 小说扉页的衬线书名
- 档案馆灯光下的米白纸页
- 一点赭石，像火漆或页边批注

## 2. 色彩系统

### 2.1 核心色板

| Token | 色值 | 用途 |
|-------|------|------|
| `--ink` | `#14212B` | 主文字、主按钮、强强调 |
| `--ink-soft` | `#2A3A47` | 次级文字、说明 |
| `--paper` | `#F3EFE6` | 页面主背景（纸色） |
| `--paper-2` | `#E8E2D4` | 略深纸色、分区底 |
| `--mist` | `#C5D0C8` | 柔和分隔、次要装饰 |
| `--sea` | `#1F5C5A` | 品牌强调、链接、选中态 |
| `--sea-bright` | `#2F8A86` | 悬停、亮一点的强调 |
| `--ember` | `#C45C26` | 点缀（类型标签、少量高亮） |
| `--line` | `rgba(20, 33, 43, 0.12)` | 分割线、描边 |
| `--shadow` | `0 18px 50px rgba(20, 33, 43, 0.12)` | 轻阴影（少用） |

### 2.2 使用原则

1. **大面积用纸色**，墨色只用于字与关键操作，避免大块黑底（首屏英雄区除外）。
2. **青绿（sea）是品牌色**，用于链接、选中、标签、关键交互反馈。
3. **赭石（ember）克制使用**，只做类型标记或极少量点缀，不要铺满。
4. **不要**默认做成紫渐变、靛蓝科技风、或高饱和多色标签墙。

### 2.3 背景层次

页面背景建议保持「有空气感」的纸色，而不是死平一色：

```
底层：纸色渐变（#EFE9DC → #F3EFE6 → #EBE6DB）
可选：极淡的青绿 / 赭石径向光晕（透明度 ≤ 18%）
```

首屏（广场 Hero）可用深色全幅平面，与内页纸色形成「封面 → 内页」的翻书感。

### 2.4 语义色（后续补全）

| 语义 | 建议方向 |
|------|----------|
| 成功 | 偏 `--sea` 的绿，勿用荧光绿 |
| 警告 | 偏 `--ember` 的暖色 |
| 错误 | 沉稳砖红，避免亮粉红 |
| 信息 | `--ink-soft` 或淡青底 |

## 3. 字体系统

### 3.1 字体配对

| 角色 | 推荐 | 中文回退 | 用途 |
|------|------|----------|------|
| **Display** | Fraunces | 宋体 / Songti SC / Noto Serif SC | 品牌名、页面大标题、世界观名、Wiki 标题 |
| **Body** | Outfit | 苹方 / 微软雅黑 / Noto Sans SC | 正文、导航、按钮、表单 |

> 气质来源：衬线标题 = 书名；无衬线正文 = 现代阅读舒适度。

### 3.2 字号阶梯（Web，参考）

| 级别 | 大小 | 字重 | 场景 |
|------|------|------|------|
| Display XL | 42–72px | 700 | 广场品牌名 |
| Display L | 28–40px | 700 | 页面主标题 |
| Display M | 22–28px | 700 | 区块标题、卡片名 |
| Title S | 16–18px | 500–600 | 列表项标题 |
| Body | 15–16px | 400 | 正文 |
| Caption | 12–13px | 400 | 元信息、时间、标签 |
| Eyebrow | 12px | 400–500 | 英文小节标题，字距加宽 |

### 3.3 排版细节

- 正文行高约 **1.55–1.7**
- 标题行高约 **1.15–1.25**，可略收紧字距（`letter-spacing: -0.02em`）
- Eyebrow / 标签：`letter-spacing: 0.12em–0.16em`，大写英文
- 长文（Wiki、小说）单列宽控制在约 **36–42em**，避免一行过长

## 4. 形状、线与空间

### 4.1 圆角

| 元素 | 圆角 |
|------|------|
| 卡片 / 面板 / 输入框 | **4px**（偏纸张裁切，不要大圆角） |
| 按钮 / 导航胶囊 | **999px**（胶囊，与卡片形成对比） |
| 封面图 | 0 或跟随卡片 4px |

### 4.2 描边与阴影

- **默认用细线描边**（`--line`），不用厚边框
- 阴影仅用于悬停抬起或浮层，**日常列表不要人人带阴影**
- 避免多层阴影、发光描边

### 4.3 间距

- 页面水平边距：约 **4vw**，内容最大宽约 **1120px**
- 区块垂直节奏：约 **3–4rem**
- 卡片内边距：约 **1–1.25rem**
- 原则：**宁肯留白，也不要塞满**

### 4.4 布局气质

- 首屏：登录后第一视线是 **作品列表**（不是世界观卡片墙）；未登录可用简短品牌区。内页：顶栏 + 单栏或「侧栏目录 + 主文」
- **默认少用卡片网格堆砌**；广场主内容用作品列表（作品名 + 所属世界），世界观卡片放在下方次要区

## 5. 组件视觉规范

### 5.1 顶栏

- 半透明纸色 + 轻微模糊，细底边线
- 左侧：**无限企划**（衬线）+ 小号英文副标
- 右侧：文字导航；主操作（控制台）用深色胶囊按钮

### 5.2 按钮

| 类型 | 样式 |
|------|------|
| Primary | 墨色底 + 纸色字；悬停转青绿 |
| Ghost | 细描边 + 半透明白底；悬停描边变青绿 |
| Nav pill | 未选中灰字；选中淡青底 |

### 5.3 世界观卡片（广场）

- 上：封面区（可用渐变/插画，高度约 140–160px）
- 下：世界名（衬线）+ 简介 + 少量标签 + 元信息
- 悬停：轻微上浮 + 淡阴影，不要夸张缩放

### 5.4 作品列表项（入口页）

- 横向：小缩略图 + 标题/摘要 + 时间
- 类型用 **ember 小字大写**（小说 / 美术 / 剧情）
- 偏「更新目录」，不要做成短视频封面墙

### 5.5 世界观 Wiki 式主页

- 这是 **单个世界观的主页形态**，不是「无限企划」全站 Wiki
- **平台提供渲染器**：创建者通过 `homepage_config` 选择主题 / 布局 / 模块，不写自定义 CSS
- 默认气质仍是纸本设定集；可选墨夜、青雾、赭火等主题变体
- 布局可选：经典单栏、左侧目录、杂志双栏
- 词条互链：强调色 + 下划线感（仅链接本世界词条）
- 时间轴：左侧竖线 + 节点，年份用强调色

### 5.6 写作区

- 大面积纸色编辑区，少工具栏噪音
- 标题用衬线大字；正文舒适行高
- 侧栏放「当前世界」与「可插入词条」，像写作时摊开的设定便签

### 5.7 控制台

- 仍保持纸本色，**不要**突然变成深色 Admin 风
- 可用轻量统计块，但避免仪表盘图表堆砌
- 表单：细线输入框、清晰 label

### 5.8 标签 / Chip

- 筛选 chip：线框胶囊；选中 = sea 实心
- 内容 tag：小号 sea 色文字即可，不必人人做成实心胶囊

## 6. 动效原则

目的是 **存在感与层级**，不是装饰噪音。

建议保留 2–3 种基础动效：

1. **页面切换**：短促淡入 + 轻微上移（约 0.4s）
2. **卡片/列表悬停**：位移 2–4px + 阴影出现
3. **按钮悬停**：颜色过渡 + 轻微上移 1px

避免：循环闪烁、强弹跳、粒子特效、进场过长动画。

## 7. 图像与插画

### 7.1 方向

- 封面/头图：氛围插画、纹理、抽象地图感均可
- 可用渐变色块做占位（原型即如此），正式环境再换真实图
- 摄影若用，偏胶片、纸质、低对比，避免库存图微笑商务风

### 7.2 禁止（品牌一致性）

- 首屏贴满浮动徽章、促销贴纸
- 无意义的 3D 玻璃图标行列
- 和「书本设定集」无关的赛博霓虹主视觉

## 8. 页面应用要点

| 页面 | 视觉重点 |
|------|----------|
| **广场（登录后）** | 主内容：浏览作品（作品名 + 所属世界）；下方才是发现世界观。不要一上来推世界卡片墙 |
| **入口页** | 扉页感：世界名 + 欢迎词；下方为**该世界**最新作品 |
| **某世界的 Wiki 式主页** | 辞典感：目录 + 长文 + 词条互链（每个世界各自一份，不是全站百科） |
| **写作** | 书桌感：大编辑区 + 侧栏词条 |
| **控制台** | 同一纸本系统下的管理，不换皮肤 |

## 9. 设计交付建议（PS）

用 Photoshop 时建议：

1. 画板宽度：**1440px**（主） / 可选 1920
2. 图层分组命名：`Topbar` / `Hero` / `WorldCard` / `Welcome` / `WorkFeed` / `WikiNav` / `WikiMain`
3. 颜色建色板，与本文 Token 一致
4. 先出：广场 → 入口页 → Wiki → 写作 → 控制台
5. 导出给 AI / 开发时：整页 PNG + 简短模块说明（比强行 HTML 更清晰）
