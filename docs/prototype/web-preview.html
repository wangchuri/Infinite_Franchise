世界介绍

银轨纪元发生在人类已能沿「银轨」进行近恒星航行的时代。 城市建在巨大的轨道环上，港口灯塔负责校准航线，也负责记录那些不该被记录的离港。

核心冲突来自两套历法：官方的「港务历」与地下流传的「静默历」。 写作时请优先链接词条 灯塔守夜人、 静默区、 第三航次。
