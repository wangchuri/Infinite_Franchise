## 1. 本份灵感覆盖三块

1. **世界观浏览页**（卡片式：关注在上、推荐在下）  
2. **点进某个世界之后**（介绍 + 最新作品 → 再进 Wiki / 参与写作）  
3. **写作与 Wiki 的深度联动**（自动归属世界、词条快链、写作中产生的新概念写入 Wiki）

---

## 2. 世界观浏览页（卡片式）

与当前原型里「发现世界观」的卡片气质一致，单独成页或从广场左侧「发现更多」进入。

### 2.1 结构

```
┌─────────────────────────────────────────┐
│  我关注的世界观（上）                      │
│  [卡片] [卡片] [卡片] …                   │
├─────────────────────────────────────────┤
│  推荐的世界观（下）                        │
│  [卡片] [卡片] [卡片] …                   │
└─────────────────────────────────────────┘
```

### 2.2 卡片信息（建议）

- 封面 / 氛围图  
- 世界名称  
- 一句话简介  
- 标签、最近更新、作品数 / 词条数（可选）  

### 2.3 交互

- 点击卡片 → **该世界观入口页**（见 §3）  
- 关注 / 取消关注（登录后）  

### 2.4 原则

- 这是「找世界 / 管关注」的页面  
- **不是**登录进站的第一屏（第一屏是广场内容流）

---

## 3. 世界观入口页（点进去之后）

与现有设计一致，并明确两个主行动：

### 3.1 首屏内容

1. **世界介绍 / 创建者欢迎词**  
2. **该世界的最新作品**（只属于本世界）

### 3.2 主操作

| 操作 | 去向 |
|------|------|
| 进入 Wiki | 该世界的 Wiki 式主页（介绍、词条、时间轴、发展史等） |
| 参与写作 | 打开写作界面，**已绑定当前世界观** |

```
入口页
├── 介绍 / 欢迎词
├── 本世界最新作品
└── 行动
    ├── [查看 Wiki]
    └── [参与写作] → 写作页（自动链接本世界）
```

---

## 4. Wiki 式主页（该世界自己的）

再次强调：Wiki 是**这个世界观的主页形态**，不是平台总百科。

### 4.1 可查看内容

- 各种介绍（世界概述、设定分类）  
- **时间轴**  
- 词条：人物、地点、物品、组织、概念等  
- 发展史（可选，与正式设计对齐）

### 4.2 从入口进入

用户路径：

```
世界观卡片 → 入口页（介绍+作品）→ Wiki（深读设定）
```

---

## 5. 参与写作 · 与世界观 / Wiki 联动

这是本份灵感的重点增强项。

### 5.1 自动链接到对应世界观

- 从某世界入口页点「参与写作」→ 写作上下文**自动绑定该世界**  
- 用户无需再手动选世界（仍允许在写作页切换，若产品需要）  
- 发布后的作品默认归属该世界，并出现在：  
  - 该世界入口页的最新作品  
  - 广场内容流（带世界归属标注）

### 5.2 Wiki 快速链接

写作过程中提供：

- 输入 `[[词条名]]` 或 `@` 补全  
- 侧栏「本世界词条」一键插入  
- 已链接词条可点击跳转到 Wiki 词条页（预览 / 新开）

目的：写故事时随时够得到设定，不用离开编辑器去翻 Wiki。

### 5.3 实时（或近实时）添加 Wiki 介绍 / 词条

当作品中出现**世界观里尚不存在的新概念、物品、人物等**时：

- 系统协助将其**加入该世界的 Wiki 词条**  
- 理想体验接近「写着写着，设定库被补上了」

#### 建议的产品形态（由轻到重）

| 档位 | 行为 | 说明 |
|------|------|------|
| A. 手动标记 | 作者选中文本 →「添加为词条」 | 最可控，适合 MVP |
| B. 写作中提议 | 检测到 `[[新词]]` 或标记的新概念 → 弹出「创建词条」草稿 | 半自动 |
| C. 发布后提炼 | 发布时扫描新链接 / 新概念 → 生成待确认词条列表 | 适合审核制世界 |
| D. 更自动 | 模型辅助抽取新实体并建议词条 | 远期，需确认与权限 |

本灵感**先确立能力目标**：支持在创作流程里把新概念写入 Wiki；具体用 A/B/C 哪一档在正式设计里定。  
「实时」优先理解为：**写作会话内就能建词条 / 补简介**，而不必发完作品再去 Wiki 后台慢慢建。

#### 与权限的关系

- 若该世界 Wiki 为「需审核」：新词条先入草稿 / 审核队列，再公开  
- 若开放编辑：可直接生成公开词条（或仍建议先草稿，防误伤）  
- 词条创建者记为当前作者；世界创建者 / 编辑可改可撤

#### 词条最小字段（新建时）

- 标题（概念 / 物品名等）  
- 分类（人物 / 地点 / 物品 / 概念…）  
- 简介（可先一句，后补）  
- 来源作品（回溯链接，可选）

## 6. 端到端路径（串起来）

```
广场内容流刷到作品
    → 点世界名 / 从「关注·发现」进世界观浏览页
        → 点卡片进入入口页（介绍 + 本世界最新作品）
            → [Wiki] 看介绍、时间轴、词条
            → [参与写作]
                → 自动绑定该世界
                → Wiki 快链插入词条
                → 新概念 → 写入 / 提议写入 Wiki
                → 发布 → 回流入口页 + 广场内容流
```
