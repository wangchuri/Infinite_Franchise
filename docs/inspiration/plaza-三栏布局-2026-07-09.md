# 灵感 · 广场三栏布局

> 类型：`plaza`（广场 / 首页）  
> 日期：2026-07-09  
> 状态：灵感草案，待并入正式设计  
> 来源：产品讨论

---

## 1. 核心想法

用户进入广场后，**第一件事是看内容流（作品）**，而不是先面对世界观目录。

布局为三栏：

| 区域 | 位置 | 内容 |
|------|------|------|
| 关注的世界观 | **左侧** | 用户已关注的世界观列表 |
| 内容流 | **中间** | 最新作品流（不按世界观分区展示） |
| 活跃作者 | **右侧** | 来自「关注的世界观」里近期活跃的作者 |

> 注：口述时两侧都说成「左侧」；按常见信息架构，第三栏落在**右侧**。若你希望改成别的排布，可在本文件修订。

## 3. 中间 · 内容流（主视线）

### 3.1 原则

- **不区分世界观做分区排版**（不要「银轨专区 / 雾港专区」并排）
- 就是一条按时间（或推荐）排列的**作品流**
- 每条作品仍需标明归属，方便跳进世界，但不打断「刷作品」的心智

### 3.2 单条作品至少展示

| 字段 | 说明 |
|------|------|
| 作品名称 | 主标题，可点进作品详情 |
| 所属世界观 | 次级信息，可点进该世界入口页 |
| 类型 | 小说 / 章节 / 剧情 / 美术等 |
| 作者 | 可选 |
| 时间 | 发布时间或更新时间 |
| 摘要 / 缩略图 | 可选 |

### 3.3 流的来源（待定，可组合）

候选策略（正式设计时再定）：

1. **全站最新公开作品**（最简单，访客也能看）
2. **关注世界优先**：关注世界的作品排前面，其余补全
3. **关注 + 推荐混合**

本灵感倾向：登录后默认偏「能刷到关注世界的更新」，同时仍能刷到其他世界的公开作品，避免信息茧房过死。

## 4. 左侧 · 关注的世界观

### 4.1 作用

- 快速跳进常看的世界
- 提醒「我在跟哪些宇宙」
- **不是**进站第一关；只是侧栏导航

### 4.2 展示建议

- 世界名（必要）
- 小封面 / 色点（可选）
- 未读更新角标（可选，后续）
- 底部：「发现世界观」入口 → 进入世界观浏览页（见另一份灵感）

### 4.3 未关注时

- 展示空状态文案 + 「去发现世界观」
- 或临时展示热门世界（需标注「推荐」，避免当成已关注）

---

## 5. 右侧 · 活跃作者

### 5.1 范围

来自用户**已关注的世界观**内，近期有投稿 / 编辑 / 写作行为的作者。

### 5.2 作用

- 强化「这些人在把世界写活」的社区感
- 从作者跳到其作品或主页（作者主页若尚未设计，可先跳作品列表）

### 5.3 单条建议

- 头像 + 昵称
- 活跃于哪个世界（可多个则显示最近一个）
- 一句动态（如「更新了《雨夜档案》」）（可选）

### 5.4 未关注任何世界时

- 右侧可改为「全站活跃作者」或暂时隐藏，避免空白尴尬
